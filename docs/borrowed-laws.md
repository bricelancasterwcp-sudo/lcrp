# Borrowed laws

Short constitution. Parent repos win on conflict; this file is a map, not a fork.

## From assay

- Measure **instrument fitness**, not IQ.
- **None ≠ 0**; dropped cells name why.
- Floors and **cover** before publish; incomplete comparison ≠ green.
- Canaries for silent truncation / contract-looking HTTP 200s.
- Schema bumps do not silently rewrite old profiles.

Repo: https://github.com/bricelancasterwcp-sudo/assay

## From bloomery

- Endpoint is unreliable hardware: probe, budget, admit, journal.
- **One VRAM pool**; computed windows; refuse with arithmetic.
- Pager decisions are deterministic and replayable from the journal.
- Unmeasured → degrade mode with a cap, never a fake precise budget.
- Weights/patches/KV accounting mistakes are OOMs or silent quality death —
  treat accounting as load-bearing.

Repo: https://github.com/bricelancasterwcp-sudo/bloomery

## From sensorium

- Record what ran; answer only from the record.
- Refuse by name when the trace cannot settle the question.
- Deeper capture is licensed only after shape-match (when using refocus).
- Overhead is opted into (`--focus`), not a surprise.

Repo: https://github.com/bricelancasterwcp-sudo/sensorium

## LCRP-specific addenda

- Patches are residents, not prompts: retrieval quality is a **systems**
  property (pin, prefetch, digest) as much as an ML property.
- Core must be trained/evaluated with patches off; otherwise the split is fake.
- “Beats W4” is gated (see gates.md); marketing language is forbidden in-tree
  until gates pass on committed evidence.
